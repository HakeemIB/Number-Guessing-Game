# Number Guessing Game

This is about a console game in C# where a random number is picked from the range of 1-100 and you have to guess the number within a set number of guesses.

# Mechanics
1. There is a guesses counter and max number of guesses.
2. There is an indicator that tells you whether your input is not a number or out of range.
3. It tells you if your guesses number is Higher or lower than the number.

## How to run
Requires the .NET SDK.

    dotnet run

## What I practised
- Loops and conditionals
- Random number generation
- Input validation
